# Executive summary

## Purpose

The Valheim QoL CM project aims to enhance the gaming experience for a group of casual players by allowing them to adjust game mechanics related to experience loss upon death. This plugin will provide essential quality-of-life features that cater specifically to the needs of the group, ensuring a more enjoyable gameplay experience.

## Who

The primary users will be a group of friends playing Valheim on a server hosted through Steam Services. The solo developer will implement the plugin using Cursor AI.

## In scope

Features include an in-game console for admin users, modifiable settings affecting gameplay, and the ability to adjust the death penalty percentage. The plugin must work with the latest version of Valheim and adhere to BepInEx development requirements.

## Out of scope

The project will not include advertisements, automated ban features, or any online dependencies beyond critical plugins such as BepInEx or Jotun.
